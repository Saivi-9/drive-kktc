# Drive KKTC — Scenic Driving Routes & Travel Explorer

A responsive React + TypeScript + Vite web application designed for exploring scenic road trips, coastal drives, and cultural landmarks across Northern Cyprus (KKTC).

## Features

- **Curated Route Cards (`src/components/cards/RouteCard.tsx`)**: Highlights distance, difficulty, region, and scenic highlights.
- **Featured Routes & Category Filtering (`src/pages/Explore/Explore.tsx`)**: Filter drives by coastal, mountain, and historical categories.
- **Centralized Theme & Config (`src/constants/`)**: Typed design tokens, regional metadata, and route datasets.

## Quick Start

```bash
npm install
npm run dev
```

## Build & Lint

```bash
npm run lint
npm run build
```
